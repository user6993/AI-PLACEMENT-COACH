# Project Plan

## Phase 1 — Foundation
- Initialize the FastAPI backend and SQLite configuration.
- Add JWT-based auth and secure password hashing.
- Provide a seed dataset for demo-driven testing.

## Phase 2 — Student workflow
- Resume analysis, skill-gap tracking, job matching, interview prep, and roadmap items.
- Add dashboard metrics and activity timelines.

## Phase 3 — Frontend experience
- Create a polished React dashboard with router navigation and reusable widgets.
- Add charts, cards, tables, and responsive side navigation.

## Phase 4 — Quality assurance
- Validate API responses with tests.
- Verify the frontend production build.
- Document setup, environment variables, and deployment steps.
